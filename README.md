# Card Game Bot

## Overview
This repository contains a bot for playing card games. It includes different game components with handlers, game logic, and a manager to control the game flow.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<your_username>/CardGame.git
   cd CardGame
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the bot with:
```bash
python main.py
```
